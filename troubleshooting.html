RECOVERY AND SUPPORT

KEEP THE SHOW RUNNING

Follow these safe recovery steps when Limelight cannot connect, import a mod, initialise the Live Loader, or complete a switch.

Quick Recovery Checklist

Most testing problems can be resolved without reinstalling Dead as Disco or deleting your mod library.

01

Close Dead as Disco

Wait until the game process has completely disappeared before repairing loader files or clearing a live session.

02

Restart Limelight

Reopening Limelight clears temporary application state and lets it inspect the previous session.

03

Check the connected game

Open Settings and confirm that the selected directory is the main Dead as Disco folder.

04

Use Repair Live Loader

Open Settings, select Support, and run Repair Live Loader while the game is closed.

05

Launch through Limelight

Start a fresh managed session and wait for the in-game initialisation overlay to finish.

Game Directory Is Not Accepted

Select the main Dead as Disco installation directory, not one of its internal folders.

D:\SteamLibrary\steamapps\common\Dead as Disco

The selected directory should contain the Pagoda folder. Do not select Pagoda, Binaries, Win64, Paks, or the executable itself.

If the correct directory is rejected, verify Dead as Disco through Steam and confirm that the installed build is supported by the current Limelight version.

Live Loader Is Offline

  • Confirm the game was launched through Limelight.
  • Confirm that a Live Loader mode was selected.
  • Keep Limelight open while the game starts.
  • Wait for the initialisation overlay to complete.
  • Close the game before using Repair Live Loader.
NO LIVE LOADER MODE

If you deliberately selected No Live Loader, an offline loader status is expected. The game can still be played, but live switching will not be available.

Initialisation Does Not Finish

The first startup scan can take longer than later launches. Limelight waits for UE4SS, the Lua bridge, the native bridge, and Unreal's object system before enabling switching.

If the game reaches a playable level but the initialisation overlay eventually reports a failure:

  1. Close Dead as Disco completely.
  2. Open Limelight's Support settings.
  3. Select Repair Live Loader.
  4. Wait for the repair to finish.
  5. Launch the game through Limelight again.

Return the Game to a Clean Mod State

Early Access includes a recovery action for clearing every deployed mod from Dead as Disco's active mod directory. Use it when you need a clean game folder for leaderboards, compatibility testing, or conflict recovery.

  1. Close Dead as Disco completely.
  2. Open Settings in Limelight.
  3. Select the Support category.
  4. Select Purge All Mods.
  5. Read the warning and confirm the purge.
YOUR LIMELIGHT LIBRARY IS PRESERVED

Purge All Mods clears the game's Pagoda\Content\Paks\~mods folder and stale deployment state. Imported mods, renamed library entries, profiles, and X19 groups stay safely stored in Limelight.

MANUALLY COPIED FILES ARE REMOVED TOO

The purge removes everything inside the game's ~mods folder, including files copied there outside Limelight. Limelight cannot restore those manual files afterward.
