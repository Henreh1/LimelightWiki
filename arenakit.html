ARENA MODS ARE BACK

Limelight ArenaKit is a visual authoring, compatibility, building and packaging toolkit for custom Dead as Disco arenas.

What ArenaKit Is

Arena modding stopped working as the game and its Unreal content changed. ArenaKit restores a current, repeatable route for creating a new arena or bringing an older editable arena project forward.

The app opens the included authoring project, runs the official Unreal tools, checks the result and produces the complete arena package expected by the game.

ARENAKIT IS NOT AN SDK

ArenaKit does not contain private game code, extracted game assets or Unreal Engine. It is an authoring and compatibility toolkit built around a clean project and the public Epic Games Launcher version of Unreal Engine 5.7.

Before You Begin

  • Windows 10 or Windows 11, 64-bit
  • A legal copy of Dead as Disco
  • Epic Games Launcher
  • Unreal Engine 5.7 installed through the Launcher
  • Around 40 GB of free space before installing Unreal Engine

The Unreal installation itself is roughly 27 GB. You do not need Unreal Engine source code, an Epic-linked GitHub account, Visual Studio or a 300–400 GB custom editor build.

KEEP THE RELEASE TOGETHER

Extract the complete ArenaKit ZIP into a normal writable folder. Do not run the app from inside the ZIP and do not move only LimelightArenaKit.exe. The Project, Scripts, Docs and Compatibility folders must remain beside it.

Install and Connect ArenaKit

01

Download the current release

Download ArenaKit from the official GitHub Releases page and extract the whole ZIP.

02

Install Unreal Engine 5.7

In Epic Games Launcher, open the Unreal Engine Library and install Unreal Engine 5.7.

03

Open ArenaKit

Run LimelightArenaKit.exe and select Find UE 5.7.

04

Connect the game

Choose the main Dead as Disco directory containing Pagoda.exe and the Pagoda folder.

Create a New Arena

01

Reset to the starter

Select Reset to Starter. ArenaKit backs up the current working map before creating a clean playable template.

02

Open the editor

Select Open Editor. Replace actors marked [REPLACE] and keep or resize the gameplay actors marked [KEEP].

03

Save and close Unreal

Save every mesh, material, texture, light, effect and level change, then close Unreal Editor before building.

04

Build the arena

Select Build Only to create a checked package or Build + Install to also copy it into the connected game.

The Playable Starter

The starter is more than an empty floor. It provides the gameplay structure a working arena needs:

  • A safe Player Start
  • Enemy navigation and reachable spawn space
  • Blocking side boundaries
  • A launch-safety ceiling
  • Fall protection and a safe Kill Z
  • Preview lighting and atmosphere
  • A generated Recast NavMesh
THE MAP LOADS, BUT NO ENEMIES APPEAR

This normally means the floor has no usable collision or the NavMesh cannot reach the enemy spawn area. In Unreal Editor, show navigation and confirm that the playable floor is covered by reachable navigation before rebuilding.

The default replacement path is /Game/Pagoda/Levels/Arenas/Default/LI_Arena_Default. Do not rename or move the working map unless a future ArenaKit compatibility profile specifically supports a different target.

Patch an Older Arena

If you still have an older editable .uproject, open the Legacy Patcher. ArenaKit copies the project into its own working area, repairs known outdated editor references and rebuilds it through the current pipeline.

The original project remains untouched. Keep that original as your permanent backup even after a successful patch.

A COOKED PAK IS NOT THE ORIGINAL PROJECT

Cooking removes editor information. ArenaKit cannot promise to reconstruct a complete editable project when the only surviving copy is a cooked .pak.

Build Output and Installation

A finished ArenaKit build contains:

YourArena_P.pak YourArena_P.utoc YourArena_P.ucas LimelightArenaKit.json

The game uses the three container files. ArenaKit creates the JSON automatically so the build can be identified and managed. You never need to write the ArenaKit JSON by hand.

For manual installation, use:

Dead as Disco\Pagoda\Content\Paks\~mods
ONE REPLACEMENT AT A TIME

Only enable one mod that replaces the same arena. Two packages targeting LI_Arena_Default will conflict, and whichever package wins the load order may not be the one you expected.

Security Scanner Warnings

ArenaKit is currently an unsigned community tool. It launches PowerShell and official Unreal utilities to cook and package arenas. Behaviour-based security scanners may flag those actions even when they do not report a named malware detection.

  • Download releases only from the official repository.
  • Compare the ZIP checksum with the published release notes.
  • Keep the app and scripts together in a normal extracted folder.
  • Review the public source before running it if you are unsure.

The SHA-256 for the official v0.1.0 Windows ZIP is:

21AA8EE7ECF6B77BF0D5D4E4CF90DB20777F8E9AC6CD7EDE72362F331D1A31D3

Getting Help

When reporting a problem, include the ArenaKit version, Unreal Engine version, game build, exact steps and the relevant part of the activity log. Start with the first real error rather than only the final exit-code message.
