GETTING STARTED

WELCOME TO LIMELIGHT

This guide will take you from a fresh Limelight installation to launching Dead as Disco with your first managed character mod.

Before You Begin

Limelight is a Windows mod manager built specifically for Dead as Disco. Make sure the game is installed through Steam and has been launched normally at least once.

  • Windows 10 or Windows 11, 64-bit
  • A legitimate Steam installation of Dead as Disco
  • A supported version of the game
  • Enough free space for your imported mods
  • ZIP archives containing valid Unreal package files
EARLY ACCESS

This documentation covers Limelight Early Access. Features and compatibility requirements may continue to change as the project grows.

Install Limelight

Limelight is currently distributed as a portable test package. It does not need to be placed inside the game directory.

01

Extract the test package

Extract the complete Limelight ZIP into a normal, writable folder such as Documents. Do not run the application from inside the ZIP archive.

02

Keep the package together

Do not move only the executable. The Payloads folder and supporting files must remain beside Limelight.exe.

03

Open Limelight

Start Limelight.exe. The splash screen will appear while the application prepares its settings and managed services.

Connect Dead as Disco

On the first launch, Limelight will ask for the directory where Dead as Disco is installed.

Select the main game directory containing the Pagoda folder. A typical installation looks like this:

D:\SteamLibrary\steamapps\common\Dead as Disco

Do not select the Pagoda, Binaries, Win64, or executable folders individually. Limelight needs the main Dead as Disco directory so it can validate the complete installation.

COMPATIBILITY CHECK

Limelight checks the connected game build before enabling managed loader installation. Early Access supports Steam build 24086779 with executable compatibility label ++brainjar+release-CL-29846.

The current managed safety profile expects Native Bridge 0.1.10. Repair Live Loader installs and verifies the supported bridge files for this profile.

Import Your First Mod

01

Select Import Mod

Use the Import Mod button on the Dashboard and choose the ZIP archive you downloaded.

02

Let Limelight inspect it

Limelight safely extracts the archive, locates its PAK, UCAS, and UTOC files, and scans the contained Unreal asset paths.

03

Open My Mods

The imported mod will appear in your character library. You can rename it without changing its stored files.

04

Select Activate

Activating a mod marks it as the current model. If the game is already running with the Live Loader, Limelight will perform a safe live switch.

Choose a Launch Mode

When you select Launch Game, Limelight asks which loading mode you would like to use.

Live Loader

Starts Dead as Disco with Limelight's managed UE4SS and native bridge. You can activate compatible mods without restarting the game. The Setting the Stage overlay remains in front while Limelight verifies UE4SS, the Lua bridge, the native bridge, mounts and reloads an active mod when one is selected, and completes a final native health check.

X19 LLoader

Uses a configured group of mods that can be rotated with a keyboard or controller button. The group can follow your chosen order or use shuffle mode.

No Live Loader

Starts the game without Limelight's live-switching session. This reduces startup time and resource usage when you do not need to change mods while playing.

SAFE STARTUP HANDOFF

Dead as Disco may become visible behind the startup overlay before the Live Loader is ready. Leave the overlay open. Limelight returns focus to the game only after the complete startup check succeeds. The first resolver discovery can take longer than later launches.

Switch Mods Safely

Unreal Engine temporarily tears down and rebuilds game objects during level loading and teardown. Limelight blocks switching while this is happening. Retry only after the new level is fully visible and the transition lock has cleared.

  • Wait until the new level is fully visible.
  • Do not repeatedly press the X19 hotkey during a switch.
  • Wait for the in-game Limelight indicator to finish.
  • Keep Limelight open while using either Live Loader mode.
  • Restart the game if Limelight reports that the session needs recovery.
DO NOT FORCE A SWITCH

If Limelight says that a level change or previous switch is still in progress, wait before trying again. This protects the game from unsafe asset reloads.

Your Next Step

You now know how to connect the game, import a mod, and choose the right launch mode. The Live Loader guide explains what happens during an in-game switch.
