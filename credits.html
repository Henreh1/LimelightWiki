BEHIND THE SPOTLIGHT

CREDITS & ACKNOWLEDGEMENTS

Limelight is an independent community project made possible by open-source tools, mod authors, testers, and the wider Dead as Disco community.

Limelight

CREATED BY HENREH

Limelight, its desktop application, visual identity, documentation, installer, and Native Bridge were designed and developed by Henreh (that's me writing this!).

L

Limelight

The desktop mod manager, live-loader controller, profiles, installer, and supporting application services.

VIEW PROJECT →
NB

Limelight Native Bridge

The native Unreal bridge that makes transition-aware mounting and live asset refreshes possible in game. This started as a simple PowerShell command, but it is now embedded as a core part of Limelight itself!

VIEW PROJECT →

Open-Source Foundations

These projects provide important parts of Limelight's runtime, asset inspection, and optional Discord integration.

01

RE-UE4SS

The Unreal Engine scripting and runtime modding foundation used by Limelight's managed Live Loader.

OFFICIAL REPOSITORY →
02

CUE4Parse

Used to inspect Unreal Engine mod packages and identify the assets an activated mod replaces.

OFFICIAL REPOSITORY →
03

Discord Rich Presence

Lachee's C# library powers Limelight's optional Discord Rich Presence integration.

OFFICIAL REPOSITORY →
04

.NET & WPF

Microsoft's .NET platform and Windows Presentation Foundation power Limelight's desktop interface.

There are so many talented people out there making mods!
