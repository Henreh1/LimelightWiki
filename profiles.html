REUSABLE CHARACTER CASTS

BUILD YOUR PROFILES

Organise installed character mods into named casts, edit them whenever your library changes, and send a complete profile to X19 without rebuilding the rotation by hand.

What Is a Profile?

A profile is a saved group of installed character mods. It is useful for keeping themed casts, favourites, or a regular X19 rotation together.

Profiles only remember which installed mods belong to the group. They do not copy, move, or reinstall the mod files, so the same character can safely appear in more than one profile.

YOUR MOD LIBRARY STAYS IN CONTROL

Deleting a profile does not delete its character mods. Removing a mod from Limelight removes the unavailable entry when the profile is next edited.

Create a Profile

01

Open Profiles

Select Profiles from Limelight's main navigation to open the profile library.

02

Name the cast

Choose a short, recognisable name such as Favourites, Uma, or Stream Night.

03

Select the characters

Choose every installed character that belongs to this reusable group.

04

Save the profile

Limelight creates a compact profile card and keeps the group between launches.

Use the Profile Library

Saved profiles appear as compact cards, similar to files in an explorer. Each card shows its name, character count, and a short monogram.

  • A one-word name uses its first three letters where they fit.
  • A multi-word name uses up to three initials.
  • Select Open to enter the full profile editor.
  • The editor contains the rename, membership, X19, and delete controls.

This keeps the main profile library tidy even when several casts have been created.

Edit or Delete a Profile

Open a profile card to change its name or character selection. Save Changes commits the new version.

Use the back control to return to the profile library. If the selection has not been saved, the stored profile remains unchanged.

DELETING A PROFILE

Delete removes the saved group only. Installed mods remain in My Mods and can be added to another profile.

Use Profiles with X19

Profiles can fill an X19 rotation in two ways. Set as X19 from the profile editor replaces the current rotation with that profile's available characters.

You can also select one or more profile groups from the Live Loaders page. Limelight combines the selected groups into the final rotation and removes duplicates.

NO DOUBLE SELECTIONS

While a profile is selected for X19, its characters are hidden from the individual mod selector. Removing the profile returns those characters to the selector.

When Your Library Changes

Profiles refer to Limelight's installed mod entries. If a character is renamed, the profile follows that mod and shows the new display name. If it is removed, Limelight skips it rather than creating a broken X19 entry.

Open and save the profile after making large library changes so its membership reflects the cast you want.

Your Next Step

With a profile ready, configure its order, shuffle mode, and keyboard or controller input through X19 LLoader.
