EARLY ACCESS STATUS

THE CATALOGUE IS BETWEEN ACTS

Limelight's built-in Nexus catalogue is temporarily unavailable while its public Nexus Mods access is prepared.

Current Status

UNDER CONSTRUCTION

Browse Nexus, account connection, and direct downloads are locked during Early Access. This prevents Limelight from relying on a private testing key or an unfinished public authentication flow.

The rest of Limelight remains available. You can still download compatible mod archives from Nexus Mods in your browser and import them into Limelight normally.

Install a Nexus Mod Manually

01

Download the mod ZIP

Open the mod's Nexus Mods page in your browser, choose the correct file, and download its ZIP.

02

Import the archive

Select Import Mod on the Limelight dashboard, or drag the ZIP anywhere onto the Limelight window.

03

Check My Mods

Limelight validates the archive, blocks duplicate packages, and adds a valid mod to your library.

READ THE MOD PAGE FIRST

Check the author's requirements and installation notes. Limelight supports Dead as Disco package archives, but it cannot make an incompatible mod safe or current.

What Still Works

  • Importing compatible ZIP archives
  • Dragging mod ZIP files onto the Limelight window
  • Archive validation and duplicate-package detection
  • Renaming and organising imported mods
  • Profiles and X19 rotation groups
  • Normal and X19 live switching

What Will Return

  • The complete Dead as Disco catalogue inside Limelight
  • Title search, categories, sorting, and paging
  • Embedded descriptions and image galleries
  • File selection and download tracking
  • Approved public Nexus Mods authentication

These features will be restored after the public integration has been reviewed and can be offered without asking users for personal API keys.

Choose a File

Select View Files from the embedded mod details page. Limelight requests the files currently available for that mod and displays their version and description information.

Always read the author's instructions before selecting a file. Some mods may offer optional versions, compatibility patches, or archives intended for manual installation.

Download Behaviour

Nexus Mods Premium

Nexus Mods permits supported direct API downloads for connected Premium accounts. Limelight can track the download, validate the archive, and pass it into the normal mod import process.

Free Nexus Mods Accounts

During personal-key testing, direct API downloads may not be available to free accounts. Limelight will explain this and direct the user to the Nexus Mods website for a manual download.

DOWNLOAD FAILED DOES NOT MEAN THE MOD IS BROKEN

If Limelight reports that a Premium account is required, the limitation applies to the direct download method. You may still download the file manually from Nexus Mods and import its ZIP through Limelight.

The Downloads Page

Downloads provides one place to review current and recent Nexus download activity.

  • Queued downloads
  • Current transfer progress
  • Completed downloads
  • Automatic installation results
  • Failed or cancelled downloads
  • Messages explaining manual-download requirements

Keep Your Account Safe

  • Never send your personal API key to another person.
  • Do not include it in screenshots or diagnostic reports.
  • Do not commit it to GitHub or another source repository.
  • Disconnect Limelight before sharing your Windows account.
  • Revoke the key through Nexus Mods if you believe it was exposed.

Limelight is designed to follow the Nexus Mods API rules and will move to the approved public authentication flow before Nexus integration is enabled.
