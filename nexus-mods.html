BUILT-IN MOD DISCOVERY

NEXUS MODS

Browse the Dead as Disco catalogue, inspect mod descriptions, view images and files, and manage downloads without leaving Limelight.

Private Testing Access

Limelight's private test builds currently use a personal Nexus Mods API key. This allows the Nexus integration to be developed and tested before Limelight receives its public registered application flow.

PRIVATE TESTING ONLY

Do not distribute your personal API key. The public Limelight release will not expect ordinary users to create or paste personal API keys.

Connect a Nexus Account

01

Open Settings

Select Settings from the Limelight sidebar, then open the Nexus Mods category.

02

Enter the testing API key

Paste the personal API key created through your Nexus Mods account settings.

03

Select Connect

Limelight validates the key and displays the connected Nexus Mods username when the request succeeds.

CREDENTIAL PRIVACY

Limelight stores the key for the current Windows account and does not include it in exported diagnostic reports. Selecting Disconnect removes the saved connection.

Browse the Catalogue

Open Browse Nexus from the main navigation. Limelight loads the Dead as Disco catalogue into pages so the complete collection can be explored without rendering every result at once.

Search

Search compares your words with mod titles and supports approximate matching for small spelling mistakes. You can also paste a Dead as Disco Nexus link or enter a numerical mod ID for an exact lookup.

Categories

Use the category selector to narrow the catalogue to groups such as character replacements and other categories provided by Nexus Mods.

Sorting

Use the sorting selector to change how results are ordered, including recently added or recently updated mods.

RESPECTFUL API USAGE

Limelight caches catalogue information where appropriate and uses the official Nexus Mods API. Refresh only when you need current information.

View a Mod

Select View Mod on a catalogue card to open the embedded details view. This stays inside the Browse Nexus page and provides a Back to Search control.

  • Mod name, author, version, and category
  • Summary and complete formatted description
  • A carousel of images supplied through Nexus Mods
  • Endorsement and download information
  • A Files view for available download versions
  • A link to open the complete Nexus Mods page

Images and descriptions belong to their respective mod authors and are displayed from information supplied by Nexus Mods.

Choose a File

Select View Files from the embedded mod details page. Limelight requests the files currently available for that mod and displays their version and description information.

Always read the author's instructions before selecting a file. Some mods may offer optional versions, compatibility patches, or archives intended for manual installation.

Download Behaviour

Nexus Mods Premium

Nexus Mods permits supported direct API downloads for connected Premium accounts. Limelight can track the download, validate the archive, and pass it into the normal mod import process.

Free Nexus Mods Accounts

During personal-key testing, direct API downloads may not be available to free accounts. Limelight will explain this and direct the user to the Nexus Mods website for a manual download.

DOWNLOAD FAILED DOES NOT MEAN THE MOD IS BROKEN

If Limelight reports that a Premium account is required, the limitation applies to the direct download method. You may still download the file manually from Nexus Mods and import its ZIP through Limelight.

The Downloads Page

Downloads provides one place to review current and recent Nexus download activity.

  • Queued downloads
  • Current transfer progress
  • Completed downloads
  • Automatic installation results
  • Failed or cancelled downloads
  • Messages explaining manual-download requirements

Keep Your Account Safe

  • Never send your personal API key to another person.
  • Do not include it in screenshots or diagnostic reports.
  • Do not commit it to GitHub or another source repository.
  • Disconnect Limelight before sharing your Windows account.
  • Revoke the key through Nexus Mods if you believe it was exposed.

Limelight is designed to follow the Nexus Mods API rules and will move to the approved public authentication flow before its Nexus-enabled public release.
