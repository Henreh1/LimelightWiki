YOUR DATA AND LIMELIGHT

PRIVACY

Limelight is designed to keep application settings, imported mods, and diagnostic information under the user's control.

Privacy Overview

Limelight is a standalone desktop application. It does not require a Limelight account and does not automatically upload diagnostic reports.

The Early Access build does not include advertising, behavioural analytics, or hidden usage tracking.

EARLY ACCESS

This page describes Limelight's current Early Access behaviour. It will be reviewed and expanded as the application develops.

Data Stored Locally

Limelight stores the information needed to preserve your library and application preferences on your Windows account.

  • The connected Dead as Disco directory
  • Imported mod names and local identifiers
  • Mod installation directories
  • Scanned Unreal asset manifests
  • The currently selected mod
  • X19 group membership and ordering
  • X19 shuffle and input settings
  • Discord Rich Presence preference
  • Optional resource overlay preference
  • Live-session recovery information
  • Local LimelightMP session and diagnostic logs

Limelight's application data is normally stored beneath:

%LOCALAPPDATA%\Limelight

Imported Mod Files

Imported archives are extracted into Limelight's local mod library. Limelight scans their package information to learn which Dead as Disco assets they replace.

These files remain on the user's computer. Removing a mod through Limelight removes its managed library entry and associated local files.

MOD AUTHOR CONTENT

Imported mod files belong to their respective authors. Limelight does not grant permission to redistribute, reupload, or claim ownership of another creator's work.

Nexus Mods Connection

Nexus Mods account connection, catalogue browsing, and direct downloads are temporarily disabled during Early Access while Limelight's public integration is prepared.

Early Access does not ask ordinary users to provide a personal Nexus Mods API key. Compatible archives downloaded manually through a browser can still be imported into Limelight.

This section will be updated when the approved public authentication flow becomes available.

Discord Rich Presence

Discord Rich Presence is optional. When enabled and the Discord desktop client is open, Limelight can display that the application is being used.

Activity details may include the selected Live Loader mode, game-session state, and the display name of the active mod. Limelight does not request or store the user's Discord password.

Rich Presence can be disabled from Limelight's General settings.

LimelightMP Connections

LimelightMP is an optional experimental feature. When the user chooses Host or Join, it uses the supplied private network address to connect two copies of Dead as Disco and relay the joining player's controls to the host.

The short friend code contains the host address, connection ports, and temporary session authentication information. Limelight does not publish the code or upload it to a Limelight service. Players choose how to share it.

TREAT FRIEND CODES AS PRIVATE SESSION INFORMATION

Send a friend code only to the intended player. Redact the code and Tailscale address from public screenshots, videos, diagnostic excerpts, and bug reports.

Diagnostic Reports

Diagnostic reports are created only when the user selects Export Diagnostic Report. Limelight does not automatically upload the resulting file.

A report may contain:

  • Limelight, Windows, and .NET version information
  • Game connection and process status
  • Installed mod count and active mod name
  • Managed loader installation status
  • Live-session status and recent errors
  • Mounted container names, sizes, and switch results
  • Recent relevant UE4SS diagnostic events
THE USER CHOOSES WHETHER TO SHARE

Review the report before sending it. Limelight keeps the exported file on the user's computer until the user chooses to share or delete it.

Resource Overlay

The optional resource overlay reads Limelight's current process resource usage, such as memory consumption. This information is displayed locally and is not transmitted by the overlay.

The resource overlay is disabled by default and can be enabled from General settings.

Third-Party Services

Some optional Limelight features communicate with external services selected by the user:

  • Steam for launching and validating Dead as Disco
  • Tailscale for the optional private LimelightMP route
  • Nexus Mods for catalogue and download functionality
  • Discord for optional Rich Presence
  • GitHub for Limelight source, releases, and documentation

Each external service operates under its own account, privacy, and acceptable-use policies.

Removing Local Data

Individual mods can be removed through My Mods. The Nexus connection can be removed through Settings.

To remove all Limelight application data, first close Dead as Disco and Limelight. Then remove Limelight's application data folder:

%LOCALAPPDATA%\Limelight

Removing this folder clears saved settings, imported mod metadata, cached catalogue information, and recovery state. Limelight will behave like a fresh installation the next time it starts.

Questions or Concerns

Privacy concerns discovered during testing should include the Limelight version, the affected feature, and a clear description of the unexpected behaviour. Never include a Nexus API key in the report.
