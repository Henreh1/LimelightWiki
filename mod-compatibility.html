MOD COMPATIBILITY

KNOW WHAT CAN TAKE THE STAGE

Limelight validates every imported archive before it reaches your library. This guide explains the package formats it accepts and what makes a mod suitable for live switching.

Archive Format

Import the complete mod as a ZIP archive. Limelight inspects the archive before extracting it and blocks paths that could write outside its private mod library.

  • The selected file must use the .zip format.
  • The archive must contain at least one .pak file.
  • IoStore mods must include matching .utoc and .ucas files.
  • An accompanying .sig file is accepted when the mod provides one.
KEEP THE SET TOGETHER

Do not remove files from an IoStore mod before importing it. Its PAK, UTOC, and UCAS files work together as one container set.

Best Fit for Limelight

Limelight is designed primarily for Dead as Disco replacement mods. Character packages are the main focus, but the asset manifest can also include the supporting content that gives a replacement its complete appearance.

01

Character assets

Skeletal meshes, skeletons, physics assets, animation blueprints, materials, and textures used by the player model.

02

Presentation assets

Character portraits and other packaged interface images that the replacement intentionally overrides.

03

Localisation assets

String tables and related packaged data used to replace the displayed character name or supporting text.

Importing and Live Switching Are Different

A mod can pass Limelight's archive validation and still contain assets that Unreal Engine cannot safely refresh in the middle of a running level. Import compatibility confirms that the package set is complete. Live-switch compatibility depends on the assets inside it and the current game state.

  • Replacement assets should target paths already used by Dead as Disco.
  • The mod should be made for the connected version of the game.
  • Switch only when Limelight reports that the game state is safe.
  • Wait for the in-game indicator to finish before requesting another switch.
  • Restart the game if Limelight marks the live session as interrupted.
LEVEL CHANGES ARE TEMPORARILY LOCKED

Unreal tears down and recreates objects during a level transition. Limelight blocks activation at that point to avoid unsafe reloads and crash dumps.

Content Limelight Does Not Manage

Limelight's importer keeps supported Unreal package files. A mod that depends on separate programs or unmanaged files may require instructions from its author and should not be assumed to support live switching.

  • Standalone executables or installers
  • Unrelated DLL injection packages
  • Loose files that are not part of the Unreal container set
  • Gameplay or logic mods that require their own loader
  • Packages made for a different Dead as Disco build

Quick Compatibility Checklist

01

Import while the game is closed

Confirm that Limelight accepts the ZIP and lists the expected package files.

02

Test from a fresh launch

Activate the mod, launch through Limelight, and check its mesh, materials, textures, portrait, and displayed name.

03

Test a safe live switch

Enter a stable level, wait until loading has finished, and switch once. Confirm the complete replacement before testing again.
