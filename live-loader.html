LIVE MODDING

THE LIVE LOADER

Limelight's Live Loader lets compatible Dead as Disco replacement mods take the spotlight without requiring the game to be restarted.

What the Live Loader Does

The Live Loader connects Limelight to the running game. It mounts the selected mod's Unreal container, reloads the assets changed by that mod, and refreshes Charlie's active character mesh.

Limelight manages the required UE4SS installation, Lua bridge, and native bridge automatically. Users should not need to configure these components manually.

DESIGNED FOR REPLACEMENT MODS

The Live Loader is intended primarily for mods that replace existing Dead as Disco character assets. Mods containing unrelated executable plugins or unsupported game logic may require a normal restart.

Starting a Live Session

01

Select Launch Game

Use the Launch Game button on Limelight's Dashboard.

02

Choose Live Loader

Select the standard Live Loader from the launch mode window. Choose X19 LLoader if you want to rotate through a configured character group.

03

Wait for initialisation

Limelight waits for UE4SS, the Lua bridge, the native bridge, and Unreal's object system. If an active mod is selected, it is mounted and reloaded before a final native health check. The Setting the Stage overlay remains in front until this safe handoff succeeds, then focus returns to the game.

04

Begin playing

When the loader reports Online, compatible mods can be activated from My Mods without closing Dead as Disco.

KEEP LIMELIGHT OPEN

Limelight must remain open while a live session is active. Closing it removes the controls and progress reporting used for safe switches.

Protected Startup Discovery

Early Access uses Native Bridge 0.1.10 for the initial mount-resolver discovery. The bridge reads candidate state into guarded, stable snapshots before it follows Unreal's live objects. If Unreal changes or discards a candidate during the scan, Limelight rejects that candidate instead of using stale memory.

This reduces the known access-violation and UE4SS crash-dump risk during startup discovery. It does not make every mod, game update, or runtime state completely crash-proof.

SAFETY, NOT A DELAY

The overlay intentionally holds focus while the startup checks complete. The first discovery can take longer than later launches, especially after a repair or game update.

What Happens During a Switch

Limelight performs several checks before it changes the active character. This is why the first switch of a session may take longer than later switches.

01

Safety check

Limelight confirms that the game is running, the bridge is online, and Unreal is not changing levels.

02

Asset inspection

The asset manifest created during import tells Limelight which meshes, materials, textures, portraits, and localisation assets the selected mod replaces.

03

Container mounting

The selected PAK, UCAS, and UTOC files are staged and mounted with a suitable priority. Existing compatible mounts are reused where possible.

04

Asset refresh

Limelight releases the previous cached packages, loads fresh replacements, and refreshes the live Charlie character component.

Understanding Loader Status

Ready

The managed loader files are installed. The game is not currently connected to a live session.

Online

Dead as Disco and the Limelight bridge are connected. Live switching is available when the game is in a safe state.

Switching

A mod is currently being mounted or refreshed. Wait for the in-game indicator to finish before starting another switch.

Temporarily Locked

Unreal is loading or changing levels. Limelight keeps the current mod active and blocks new switches until the level becomes stable.

Interrupted

The previous session did not finish cleanly. Close the game and use the recovery tools in Settings before starting a new session.

Safe Switching Rules

SETTING THE STAGE

Please remain seated in the Dive Bar while Limelight works its magic. Do not enter a level until the Live Loader reports that it is ready. This lets the first asset scan and replacement pass finish before Unreal begins a level transition.

  • Wait until the current level is fully visible.
  • Do not switch during a loading screen.
  • Do not repeatedly press Activate or the X19 hotkey.
  • Wait for the in-game progress indicator to disappear.
  • Keep the game and Limelight open until the switch completes.
  • Restart the game if the live session reports that recovery is required.
LEVEL TRANSITIONS

Unreal destroys and recreates important objects while a level is loading or tearing down. Limelight deliberately refuses new switches during this period to avoid unsafe package and asset access. Retry only after the new level is fully visible and the transition lock has cleared.

If the Loader Does Not Connect

  1. Close Dead as Disco completely.
  2. Open Limelight and confirm that the game directory is connected.
  3. Open Settings, then select the Support category.
  4. Select Repair Live Loader.
  5. Launch the game again through Limelight.

If the problem continues, export a diagnostic report from Settings. Diagnostic reports omit private Nexus API credentials.
