RAPID CHARACTER ROTATION

THE X19 LLOADER

Build a custom group of character mods and rotate between them from inside Dead as Disco using a keyboard or controller button.

What Is X19?

X19 LLoader is Limelight's rapid switching mode. It uses the same managed Live Loader while adding a configurable group, an in-game hotkey, ordering controls, and shuffle mode.

Once configured, you can move through your selected characters without returning to the Limelight window after every switch.

DEAD AS DISCO ONLY

The X19 hotkey is listened for only while Dead as Disco is the active application. It should not trigger switches while you are using another program.

Create an X19 Group

01

Open Live Loaders

Select Live Loaders from Limelight's main navigation, then locate the X19 LLoader section.

02

Select your characters

Add individual installed character mods, select complete saved profiles, or combine both to build the rotation group.

03

Arrange the group

Drag the selected mods into your preferred order. This order is used when shuffle mode is disabled.

04

Save your selection

Limelight stores the group and restores it the next time the application is opened.

AN X19 GROUP IS REQUIRED

If X19 is selected while its group is empty, Limelight will ask you to return to Live Loaders and select at least one mod.

PROFILES KEEP CASTS TOGETHER

A saved profile can supply its complete character group to X19. Limelight hides those profile members from the individual selector and removes duplicates automatically. Learn how Profiles work.

Ordered and Shuffle Modes

Ordered Mode

Ordered mode follows the sequence shown in the X19 group. Each successful hotkey press advances to the next character, then returns to the beginning after reaching the end.

Shuffle Mode

Shuffle mode chooses the next character from the configured group rather than following its visible order. Your group membership is preserved, so shuffle mode can be enabled or disabled without rebuilding the list.

Choose a Keybind

The X19 input can be changed directly from the Live Loaders page. Select the change control button, then press the keyboard key or controller button you want to use.

  • Use a key that Dead as Disco does not already require.
  • Avoid controls used for pausing or opening menus.
  • Controller input is supported.
  • The chosen control is saved with Limelight's settings.
  • The hotkey is ignored while Dead as Disco is not focused.
INPUT SAFETY

Limelight ignores the X19 control while another switch is running, during its cooldown, or while Unreal is in an unsafe transition state.

Launch with X19

01

Select Launch Game

Start from Limelight's Dashboard after confirming that your X19 group contains the desired mods.

02

Select X19 LLoader

Limelight prepares the managed loader, starts the game, and connects the native bridge.

03

Wait for initialisation

The in-game Limelight overlay remains visible while the initial asset scan and mounting bridge are being prepared.

04

Use your chosen control

Once the session is online and the level is stable, press your configured control to request the next character.

The In-Game Indicator

X19 uses a small Limelight indicator so the switching process does not cover the action. The indicator pulses while Limelight is working.

Do not request another character until the indicator has finished. Some mods contain more assets than others, so switching time can vary.

Why a Switch May Be Blocked

Limelight may ignore or reject an X19 request when:

  • The game is loading or changing levels.
  • The previous switch has not finished.
  • The short input cooldown is still active.
  • The Live Loader bridge is offline.
  • Dead as Disco is not the focused application.
  • The selected mod is missing or no longer installed.
  • The current session needs recovery.
WAIT FOR A STABLE LEVEL

If a request is blocked during a transition, wait until the new level is fully visible before pressing the control again.
